## Project setup

### Install dependencies and run locally

```
$ npm install
$ npm run serve
```

### Build for production

```
$ npm run build
```

### Serve the production build

`npm start` serves the generated `dist/` directory, so build the project first.

```
$ npm run build
$ npm start
```

### Lint source files

```
$ npm run lint
```
